- mobile web QA;

- accessibility-oriented tests;
- visual audit tests;
- technical documentation.

## Does Not Own Today

- native mobile application;
- authentication;
- database;
- persistent backend;
- dedicated infrastructure repository;
- published shared packages;
- independently deployed API;
- native mobile QA;
- real FieldOps SaaS platform;
- desktop-specific or mobile-specific backend.

## Current Principle

One responsive web frontend, one shared backend/API boundary, one product source and one active source repository.
